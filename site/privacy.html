隐私与权限说明

适用对象：官网介绍的 Android v1.0 安装包。本说明基于发布包及相关源码的静态检查，不替代完整运行测试或法律合规审查。

这是独立开发项目，非腾讯或微信官方产品。当前安装包内置的旧版隐私政策有部分绝对化表述与实现不一致，请特别注意下面列出的本地保存、诊断日志与系统备份行为。官网说明不会自动修改 APK 内的旧政策。

1. 语音与消息如何处理

应用内置 sherpa-onnx 相关语音模型，在本机完成语音识别和文本朗读。微信消息收发依赖微信自身联网，微信相关数据处理由其平台政策约束。

应用会在本机保存消息历史、联系人及设置。当前相关实现最多保留最近 100 条消息。诊断日志可能包含通知标题、消息正文片段和识别文本，不应把它理解为“消息从不保存”或“没有敏感日志”。

2. 所需权限

  • 麦克风：用于识别语音指令和回复内容。
  • 通知使用权：用于读取微信相关消息通知。消息未显示在通知中时，功能可能受限。
  • 无障碍服务：用于读取相关微信界面并辅助输入、点击发送。该权限具有敏感能力，仅在理解用途后开启。
  • 前台服务、开机启动和唤醒锁：用于维持服务运行，可能增加耗电；实际行为受系统限制。

3. 网络权限与授权模块

发布包声明网络权限，相关源码保留云端授权、二维码获取及使用时长同步模块；当前源码配置关闭商业化功能。未完成发布 APK 的运行抓包验证，因此不承诺“零网络请求”。启用商业化模块时可能处理设备标识与使用时长，启用前应更新政策并履行必要告知。

4. 日志、备份和清理

日志可写入应用外部专属目录，不可用时回退内部目录。请勿公开上传含聊天内容、联系人或识别文本的诊断文件。应用声明允许系统备份，设备及系统备份设置可能影响副本保留。

可通过系统“应用信息 → 存储 → 清除数据”清理本机应用数据；清理或卸载并不能保证删除已导出文件、系统备份或其他副本。卸载后请自行核对备份及导出文件。

5. 使用边界

无障碍辅助发送可能受微信平台规则及风控限制；系统或微信更新也可能使功能失效。不承诺全机型兼容、官方合作或绝对安全。

语音交互仍可能分散注意力。请在安全停车或其他安全场景完成配置与测试，不要在驾驶中查看屏幕或处理复杂操作。

6. 官网与第三方下载

官网不设置账号、不加入广告或访问分析脚本。网站托管服务及 GitHub 下载服务可能按其自身政策处理访问日志、IP 地址等信息。二维码仅用于打开下载入口，不用于身份验证。

反馈请通过 项目仓库 Issues 提交。请勿附带真实聊天记录、电话、录音等私人信息。
